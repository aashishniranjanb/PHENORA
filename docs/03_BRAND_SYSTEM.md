# PHENORA Brand System

Visual identity guidelines for PHENORA web experiences.

## Logo Direction

The logo concept represents:
- **Analog Waves** (Impedance & AC Signal) transitioning to **Digital Blocks** (Adaptive Edge Computation / FPGA).
- Represents the bridge between biological behavior and silicon hardware.
- Avoids generic microscope or DNA helix symbols.

## Color Tokens

We establish a clean, deep-tech palette:

| Token Name | Hex Value | Usage | Description |
| :--- | :--- | :--- | :--- |
| **Silicon Navy** | `#0A192F` | Backgrounds & Main Headings | Technical, solid, and structural base. |
| **Phenora Green** | `#17B169` | Accents & Positive Statuses | Scientific, electrical excitation, and active state indicators. |
| **Sterile Slate** | `#F3F4F6` | Secondary Text & Light Surfaces | Neutral clean contrast. |
| **Pure White** | `#FFFFFF` | Core Titles & Highlights | High readability. |

## Typography

- **Heading Font:** `Space Grotesk` (Technical, geometric, sans-serif display feel)
- **Body Font:** `Inter` (Clean, highly legible neutral sans-serif)
